# SDD implementation

Read the task, current specification revision, parent handoffs, and repository state before editing. Acquire ownership for every file you will change. Preserve pre-existing changes and unrelated files. Make the smallest coherent change, add regression coverage, run relevant checks, and submit a result with changed files and exact commands. A submission is not acceptance.
