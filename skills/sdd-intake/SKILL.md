# SDD intake

Classify the request using the smallest workflow that can produce trustworthy evidence. Ask only questions that change scope, compatibility, cost, or external actions. Preserve the user's authorization for ordinary local work.

Return a concise objective, explicit acceptance criteria, compatibility constraints, and unresolved blockers. Do not edit repository files during intake.
