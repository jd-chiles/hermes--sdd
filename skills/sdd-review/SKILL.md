# SDD review

Inspect the current repository and specification independently from the implementer summary. Verify changed files, tests, acceptance criteria, and scope. Request concrete changes when a defect or missing evidence exists. Do not mark a board card accepted by hand; record the reviewer result through the SDD ledger.
